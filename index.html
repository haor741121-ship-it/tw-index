      存到手機

      方法一：固定網址（最推薦）用瀏覽器開 haor741121-ship-it.github.io/tw-index，這個網址永遠是最新版。iPhone 用 Safari 開 → 分享 → 「加入主畫面」，之後點圖示就能用；Android 用 Chrome 選單 → 「加到主畫面」。

      方法二：下載一次網頁檔按下方按鈕下載 tw-index.html，只要下載一次：之後每次打開，它會自動檢查有沒有更新版，有的話直接換成最新版（需要連網；沒網路時顯示檔案裡的版本）。

      iPhone 注意iPhone「檔案」App 的預覽不會執行網頁程式，下載的檔案請改用能開啟本機 HTML 的瀏覽器 App；或直接用方法一。
